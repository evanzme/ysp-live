# 央视频全频道 IPTV 直播网关 (ysp-live-docker v9.0 旗舰版)

> **极简·纯粹·单端口**：专为 NAS（群晖/威联通/绿联/极空间）、软路由及 Linux 服务器设计的一键容器化部署方案。已完整内置 Python 主网关与 Node.js Web WASM 兜底双引擎，搭载双设备热备池（Hot-Standby），实现工业级全自动故障平滑兜底。

---

## 🌟 核心特性

* **🚀 一键开机自启**：解压后仅需一条 `docker compose up -d` 即可在后台常驻运行。
* **📺 默认全量 26 路高码率超高清**：默认全部 26 个核心央视频道走设备协议原生高码流（50fps、8~12 Mbps），色彩细腻无拖影。
* **⚡ 双设备热备池 (Hot-Standby Pool)**：内存常驻主备双设备会话，当主设备达到配额或风控时 0ms 瞬间切轨，彻底告别切台转圈。
* **🛡️ 400 智能自愈与免降级重试**：遇到风控限制时现场启用热备设备自动重试，保护高码率频道不降级。
* **🛡️ 内置双引擎全自动四层兜底**：
  * 第一防线：设备投屏真 4K/8K 超高清（原生 12Mbps 明文高速流，免解密）；
  * 第二防线：1080p JCE 动态解析通道；
  * 第三防线：bkliveinfo 备用通道；
  * 第四防线：Node.js Web WASM 兜底引擎，风控期秒级无缝接管。
* **🔒 纯单端口对外**：对外仅需映射宿主机单个端口 `:8767`，双引擎内部闭环协同，电视客户端无需配置复杂端口。
* **💾 数据持久化安全**：自动映射宿主机 `./data` 目录，持久化设备注册凭据与频道状态，重启容器无需重新认证。
* **📦 零外部依赖**：内置全部 64 路独立频道（央视 30 路 + 卫视 34 路），无需任何 yaml 配置文件。

## 🚀 快速上手部署

### 第一步：一键启动
```bash
docker compose up -d
```

### 第二步：订阅配置
* **全频道订阅**：`http://<宿主机IP>:8767/all.m3u`
* **系统健康度**：`http://<宿主机IP>:8767/health`
* **实时诊断日志**：`http://<宿主机IP>:8767/diag`
